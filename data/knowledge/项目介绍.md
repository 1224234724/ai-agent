# 项目介绍

本项目是基于 Next.js 16（App Router）构建的企业级 AI Agent 对话应用，演示服务端渲染与大模型能力的结合。

## 技术栈

- 前端框架：Next.js 16.3.0、React 19.2.8、TypeScript 5
- 渲染模式：Server Components 服务端渲染，首页通过 `dynamic = "force-dynamic"` 保证每次请求都走 SSR
- 样式方案：CSS Modules，石墨 + 青绿企业控制台主题
- 大模型：通过 OpenAI 兼容协议接入，默认配置指向 DeepSeek

## 核心功能

1. SSR 演示区块：服务端渲染时间与 Node.js 版本随首屏 HTML 下发
2. 流式 AI 对话：服务端转发上游 SSE，前端用 ReadableStream 逐块渲染
3. 多人设 Agent：知行（知识运营助理）与衡策（业务决策顾问），各自独立的系统提示词
4. 企业知识库（RAG）：从 data/knowledge 目录检索相关段落并注入对话上下文

## 目录结构

- app/page.tsx：首页（企业级落地页，SSR 时加载知识库统计）
- app/admin/page.tsx：知识库管理后台（登录守卫 + 用量统计 + 文档管理）
- app/login/page.tsx：后台登录页（账号 ADMIN_USERNAME，密码 ADMIN_PASSWORD）
- app/components/Chat.tsx：聊天客户端组件（停止生成 + 会话持久化）
- app/components/AdminPanel.tsx：后台管理面板（启用/删除/上传解析/新增）
- app/api/chat/route.ts：对话接口（流式 + 工具调用 + 限流 + 审计）
- app/api/kb/route.ts：知识库管理接口（POST，需登录，支持文件上传）
- app/api/conversations/route.ts：对话历史存取（GET/POST/DELETE）
- app/api/login、app/api/logout：登录登出接口（HttpOnly 会话 Cookie）
- lib/personas.ts：企业 Agent 人设定义（前后端共用）
- lib/knowledge.ts：知识库加载、检索、启用配置与上传解析
- lib/tools.ts：Agent 工具定义与执行（外部 API 调用）
- lib/auth.ts、lib/audit.ts、lib/rate-limit.ts、lib/conversations.ts：鉴权/审计/限流/会话存储
- data/knowledge/：知识库文档（Markdown），支持上传 .md/.txt/.csv/.json 自动解析
