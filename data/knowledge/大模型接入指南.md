# 大模型接入指南

本应用通过 OpenAI 兼容协议接入大模型，支持任意兼容 OpenAI Chat Completions 接口的服务（DeepSeek、通义、本地 Ollama 等）。

## 配置方式

在项目根目录创建 .env.local 文件，支持以下环境变量：

- OPENAI_API_KEY：必填，大模型服务的 API 密钥
- OPENAI_BASE_URL：接口地址，默认 https://api.openai.com/v1；接入 DeepSeek 时填 https://api.deepseek.com/v1
- OPENAI_MODEL：模型名称，默认 gpt-4o-mini；DeepSeek 对应 deepseek-chat（对话）或 deepseek-reasoner（深度思考）

## DeepSeek 接入示例

```
OPENAI_API_KEY=sk-xxxx
OPENAI_BASE_URL=https://api.deepseek.com/v1
OPENAI_MODEL=deepseek-chat
```

## Mock 模式

未配置 OPENAI_API_KEY 时，系统自动进入本地 Mock 模式：由服务端模拟流式输出，用于无密钥环境下的功能演示与前端联调。

## 安全说明

- API 密钥只保存在服务端环境变量中，前端页面与浏览器不会接触到密钥
- .env.local 已被 .gitignore 忽略（.env* 规则），不会提交到代码仓库
- 所有大模型请求由服务端 route handler 转发，前端只与 /api/chat 通信
